    Tools¶

    The tools reach Paperless with the token this server is configured with, so they see and change only what that token's Paperless user may.

    Pages. Every list tool returns one page, with next and previous as bare page=N markers, or null at either end. Pass page=N to fetch another. The markers never carry the Paperless host name.

    Paperless versions. Requests prefer Paperless payload version 10. When Paperless rejects that version, the client session falls back to version 9 for Paperless 2.x. An authentication, permission or other failure never triggers the fallback. After upgrading a connected 2.x instance, restart this server to select version 10 again.

    Errors. A tool that cannot deliver its result returns a tool error written for the model: what went wrong and which call to make next. How it is logged depends on who has to act:

    Paperless answered The model is told Logged at
    400, 403, another 4xx, or 404 for an id the call passed what to change, or that the account may not do this INFO
    409 to read the object again and retry with its current values INFO
    429, 5xx, or no answer the request was fine; retry in a minute WARNING
    401, 404 for a call without an id, or a reply the server cannot parse the request was fine; tell the user ERROR

    Only the last row needs an operator. Anything else that fails inside a tool is logged once as tool_failed at ERROR with its traceback.

    Every tool runs with the server's own privileges; the security model says what that reaches.

    Group Tool Title Does
    Documents list_documents List Documents List documents filtered by their metadata; returns one page of metadata.
    Documents search_documents Search Documents Search the full text and metadata of documents; returns one page, best match first.
    Documents get_document Get Document Get one document's metadata, notes and custom field values, without its text.
    Documents get_document_content Get Document Text Read a document's text, up to 20,000 characters per call.
    Documents get_document_thumbnail Get Document Thumbnail Get a small image of a document's first page.
    Documents get_document_metadata Get Document File Details Get a document's file details: original and archived file names, sizes, checksums and MIME type.
    Documents get_document_notes List Document Notes List the notes on a document, with their full text.
    Documents get_document_history Get Document Audit Log List the changes made to a document: who changed which field, and when.
    Documents get_document_suggestions Suggest Tags, Correspondent and Type Get Paperless's suggested tags, correspondent, document type and dates for a document.
    Documents update_document Update Document Change a document's metadata; returns the updated document without its text.
    Documents delete_document Move Document to Trash Move a document to Paperless's trash, where a user can restore it until the trash is emptied.
    Documents upload_document Upload Document Upload a file for Paperless to consume; returns the consume task's id.
    Documents bulk_edit_documents Bulk Edit Documents Apply one operation to many documents at once; returns OK once Paperless accepts it.
    Documents add_document_note Add Document Note Add a note to a document; returns the new note with its id.
    Documents delete_document_note Delete Document Note Delete one note from a document.
    Tags list_tags List Tags List tags; returns one page with their ids and names.
    Tags get_tag Get Tag Get one tag by id.
    Tags create_tag Create Tag Create a tag; returns it with its id.
    Tags update_tag Update Tag Change a tag's name, colour, inbox flag or matching rule; returns the tag.
    Tags delete_tag Delete Tag Delete a tag and remove it from every document that carries it.
    Tags bulk_edit_tags Bulk Edit Tags Set the owner and permissions of many tags, or delete them; returns OK when applied.
    Correspondents list_correspondents List Correspondents List correspondents; returns one page with their ids and names.
    Correspondents get_correspondent Get Correspondent Get one correspondent by id.
    Correspondents create_correspondent Create Correspondent Create a correspondent; returns it with its id.
    Correspondents update_correspondent Update Correspondent Change a correspondent's name or matching rule; returns the updated correspondent.
    Correspondents delete_correspondent Delete Correspondent Delete a correspondent and clear it from every document that names it.
    Correspondents bulk_edit_correspondents Bulk Edit Correspondents Set the owner and permissions of many correspondents, or delete them; returns OK when applied.
    Document types list_document_types List Document Types List document types; returns one page with their ids and names.
    Document types get_document_type Get Document Type Get one document type by id.
    Document types create_document_type Create Document Type Create a document type; returns it with its id.
    Document types update_document_type Update Document Type Change a document type's name or matching rule; returns the updated document type.
    Document types delete_document_type Delete Document Type Delete a document type and clear it from every document of that type.
    Document types bulk_edit_document_types Bulk Edit Document Types Set the owner and permissions of many document types, or delete them; returns OK when applied.
    Custom fields list_custom_fields List Custom Fields List custom field definitions; returns one page with their ids, names and types.
    Custom fields get_custom_field Get Custom Field Get one custom field definition by id, with its select options.
    Custom fields create_custom_field Create Custom Field Define a new custom field; returns it with its id.
    Custom fields update_custom_field Update Custom Field Rename a custom field or change its options; returns the updated field.
    Custom fields delete_custom_field Delete Custom Field Delete a custom field and its value on every document.
    Storage paths list_storage_paths List Storage Paths List storage paths, the folder layouts Paperless files documents into; returns one page.
    Storage paths get_storage_path Get Storage Path Get one storage path by id, with its path template.
    Saved views list_saved_views List Saved Views List saved views, the named document filters users keep in Paperless; returns one page.
    Saved views get_saved_view Get Saved View Get one saved view by id, with its filter rules and sort order.
    Share links list_share_links List Share Links List public share links for documents; returns one page with each link's document, expiry and URL.
    Share links get_share_link Get Share Link Get one share link by id, with its document, expiry and URL.
    Tasks list_tasks List Background Tasks List Paperless background tasks such as consuming uploads and reindexing; returns one page, newest first.
    Tasks get_task Get Background Task Get one background task by id, with its status and result; returns null if there is none.
    Tasks wait_for_task Wait for Task to Finish Wait for a background task to finish; returns the task with its final status and result.
    System get_statistics Get Paperless Statistics Get counts for the whole archive: documents, inbox documents, tags, correspondents, types, characters and file types.
    System get_remote_version Check for Paperless Updates Check whether a newer Paperless-NGX release exists; returns the newest release.
    Server info get_server_info Server Info Report the version information of paperless-mcp; returns server_name, server_version, core_version, the MCP protocol revisions supported and the revision and client of this connection, and, when configured, the upstream service's version.
    Transfer create_download_link Create Download Link Create a download URL for a file; returns url and expires_in_s.
    Transfer create_upload_link Create Upload Link Create an upload URL for a file; returns url and expires_in_s.
