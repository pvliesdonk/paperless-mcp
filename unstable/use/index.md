# Use paperless-mcp

This section is for readers who already run the server and want more out of it: how to use its features for real tasks, and why they behave as they do. Each page covers one task or one feature.

For what the server can reach and change while you use it, see the [security model](https://pvliesdonk.github.io/paperless-mcp/unstable/security-model/index.md).

This server adds no workflows of its own. Each tool is one Paperless-NGX operation, listed in the [tools reference](https://pvliesdonk.github.io/paperless-mcp/unstable/reference/tools/index.md). What documents, tags and correspondents are is the subject of the [Paperless-NGX documentation](https://docs.paperless-ngx.com/).
